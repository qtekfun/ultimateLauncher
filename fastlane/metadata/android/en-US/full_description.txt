UltimateLauncher is a home screen launcher for Android 12 or later, built on AOSP's Launcher3 and designed for phones and tablets.

<b>Privacy first</b>
• It does not declare the Internet permission, so Android prevents it from opening network connections. No accounts, no ads, no telemetry, no automatic crash reports.
• No Google services (GMS), no Firebase and no networking libraries; it works the same on phones without GMS.
• No usage history, recent apps or predictions are stored. The drawer search filters in memory and does not save queries.
• Privacy checks (exact permission list, dependencies and forbidden network classes) run on every code change.

<b>What it offers</b>
• Home screen and app drawer with grid, icons, dock and folders tuned to the project's own measurements; folders can be enlarged to 2x2.
• Configurable tablet dock.
• On-demand backup and restore to a file you choose (optional encryption when exporting the layout). Nothing is sent anywhere.
• Import your home screen from another launcher's backup file (Nova, Lawnchair and similar).
• Bundled wallpapers (12, generated by code, no third-party images) and support for already installed icon packs (ADW, Nova, Apex).
• Optional swipe-down gesture on the home screen to open notifications or quick settings (off by default).
• Hide apps from the drawer and from search, protected with fingerprint, face or device PIN.
• Own digital clock widget.

<b>Permissions</b>
Host widgets (BIND_APPWIDGET), uninstall from the icon, set the wallpaper, vibration, ask the system not to kill the launcher (only if you accept it in the setup assistant), expand the status bar (optional gesture) and biometric authentication (hidden apps). None of them gives access to your personal data; there are no storage, contacts, location, camera or microphone permissions.

<b>What it does not do</b>
• No Google feed, no web search, no app suggestions or predictions.
• No cloud sync. The network flavour (WebDAV) mentioned in the code is not published here and has no network client implemented.
• No double-tap-to-lock (it would require accessibility or device-admin permissions).
• It is not a product of any phone manufacturer and contains no third-party code, assets or trademarks.

<b>Status</b>
Initial release (0.1.0), tested on a limited number of devices (Android 16 and Android 12). Some features are verified by code only; bug reports are welcome in the project repository.
